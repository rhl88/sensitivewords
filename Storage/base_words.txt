# CmsPro 敏感词过滤 · 内置常见词库
# 格式：敏感词,动作(block/replace/warn),级别(1-3),分类code
#   - block   禁止：命中即拦截，validateText 返回错误
#   - replace 替换：用掩码字符替换命中词
#   - warn    提醒：放行原文但记录命中日志
#   - 级别 1=低 2=中 3=高
#   - 分类code 对应内置分类：abuse(辱骂攻击) / ad(广告推广) / fraud(诈骗违禁) / porn(色情低俗)
# 以 # 开头的行为注释，空行忽略；文件支持 UTF-8 与 GBK 编码
#
# ── 动作与级别的取值原则 ─────────────────────────────────────────
#   block  ：明确违法违规（赌博、毒品、枪支、证件伪造、诈骗），拦截提交
#   replace：不雅但未必违法（辱骂、色情导流），掩码替换后放行
#   warn   ：存在合理正当语境、误伤率偏高（如性教育、影视术语、英文缩写），
#            仅记日志不改动原文，由管理员按站点调性决定是否加严
#
# ── 关于未内置的类目 ─────────────────────────────────────────────
#   涉政、民族宗教、地域歧视类词条高度敏感，须按属地法规与平台规范维护，
#   本文件不内置具体词条。请通过「词库维护 → 导入词库」上传自有词库，
#   或「在线更新」从版本服务同步，并在「分类管理」中为其配置动作。
#
# ── 关于误伤 ─────────────────────────────────────────────────────
#   引擎按「归一化 + 最长匹配」工作，短词与常见词的误伤风险更高
#   （如英文缩写、单字）。若发现正常内容被误伤，可在后台禁用该词条，
#   或由接入方注册 cmspro.sensitivewords.whitelist 钩子按场景放行。
